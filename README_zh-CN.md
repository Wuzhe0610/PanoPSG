# PanoPSG

[English](README.md) | 简体中文

**面向全景分割与全景场景图生成的高分辨率ERP图像数据集。**

PanoPSG将像素级场景标注与实体间语义关系相连接，在完整360°全景视野中共同描述场景实体及其关系，为全景场景解析与关系理解研究提供数据基础。

配套论文介绍的数据集包含 **340张全景图**，每张分辨率为 **11968 × 5984**，具有 **10,571个实体节点和6,632条有向关系三元组**。对象采用COCO Panoptic的133类体系，其中82类实际出现；关系采用21类谓词。

## 数据特点

- **高分辨率360°场景。** 每张图像约含7162万像素，覆盖街道、校园、公园等环境，保留丰富的场景细节。
- **全景分割与场景图关联。** thing实例与stuff区域共同构成实体节点，关系三元组连接同一组实体。
- **多谓词关系表达。** 同一有序对象对支持多个谓词，描述实体间的语义联系。
- **跨接缝实体身份。** 通过源标注分组，将ERP左右边界同一实例的可见区域关联为统一实体。
- **人工标注与复核。** 标注人员经过统一培训，全部标注经过复核，检查掩码、关系端点、重复三元组及分割与关系的对应情况。

## 采集与标注

图像由数据集创建者自行拍摄，并在整理过程中排除模糊、重复和拼接错误的图片。

全景分割掩码由人工在CVAT中标注。可辨认区域赋予对象类别，无法辨认区域标为ignore。同图同类stuff区域汇总为一个节点；跨ERP左右接缝的同一thing实例通过共同源分组，合并为一个实体和一个segment ID。

关系标注平台通过稳定实体身份关联掩码区域与关系端点。标注支持thing–thing、thing–stuff、stuff–stuff之间的关系；空间关系依据场景中的实际关系判断，包括位于ERP图像两端但现实相邻的实体。全部标注经过复核，核对端点有效性及掩码与关系的一致性。
